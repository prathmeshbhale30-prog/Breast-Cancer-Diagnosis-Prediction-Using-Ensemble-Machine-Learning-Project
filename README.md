# Breast-Cancer-Diagnosis-Prediction-Using-Ensemble-Machine-Learning-Project
Domain: Healthcare Analytics | Data Science | Machine Learning | Ensemble Learning
Description: Developed a Breast Cancer Diagnosis Prediction model using Ensemble Machine Learning. Performed EDA, statistical analysis, data preprocessing, Winsorization, and feature scaling. Implemented a Stacking Classifier combining KNN, Random Forest, and Gaussian Naive Bayes with Logistic Regression, evaluated using 3-fold cross-validation. Technologies: Python, Pandas, NumPy, Scikit-learn 
Tools: Jupyter Notebook, Anaconda, Spyder 
Techniques: EDA, Statistical Moments, Skewness, Kurtosis, Correlation Analysis, Winsorization, Min-Max Scaling, KNN, Random Forest, Gaussian Naive Bayes, Stacking Classifier, Cross-Validation
